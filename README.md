# Política de privacidade — CatchTravel

Site estático com a política de privacidade do CatchTravel, nas cores do app Android.

## Publicar no GitHub Pages (HTTPS para a Play Console)

1. Faça commit e push deste repositório para o GitHub.
2. No repositório: **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Branch: `main` (ou `master`), pasta: `/` (root). Salve.
5. Depois de alguns minutos, a página fica em:

   `https://<seu-usuario>.github.io/<nome-do-repositorio>/`

6. Cole essa URL HTTPS no campo de política de privacidade da Play Console. O mesmo texto deve aparecer no app em **Política de privacidade**.

Não há analytics nem backend: só HTML e CSS.
